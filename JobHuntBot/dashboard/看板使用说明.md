# 岗位看板

看板展示本地岗位、投递进度、每日更新和跟进事项。首次使用时在仓库根目录运行：

```sh
python3 scripts/setup.py
sh JobHuntBot/dashboard/start-dashboard.sh
```

手动打开终端显示的地址，默认是 <http://localhost:8420/dashboard.html>。保持终端打开；按 `Ctrl+C` 停止服务。需要 Node.js 20 或更新版本。

如果端口已被其他程序占用，启动会失败并明确提示，不会连接、停止或修改已有服务。可以改用其他端口：

```sh
JOBHUNT_PORT=8421 sh JobHuntBot/dashboard/start-dashboard.sh
```

页面每 60 秒自动刷新，也可手动刷新。收藏保存在当前浏览器中；导出只包含当前筛选的岗位。

## 本地资料

初始化创建空白岗位表格。个人资料、简历、岗位记录、邮箱状态和实际配置都只应保存在本地，已通过仓库忽略规则排除。不要把填好后的资料、导出文件或截图上传到公开仓库。看板只监听本机地址，不会自动上传数据或启动投递。

## 可选自动化绑定

没有配置定时任务是正常状态，不影响手动使用。先使用 [jobhunt-assistant 技能](../skills/jobhunt-assistant/SKILL.md) 创建自己的 Codex 自动化任务，再在本地 `JobHuntBot/skills/jobhunt-assistant/settings.json` 中填入对应 ID：

```json
{
  "automation_ids": {
    "screen": "your-screening-task-id",
    "gmail": "your-mail-sync-task-id"
  }
}
```

仅修改配置中的 `automation_ids` 字段，保留其他设置。空对象 `{}` 表示不绑定任何任务。看板读取已绑定任务的状态与时间，不显示自动化提示词、任务名称或本机路径。该绑定只用于展示，不会创建或更改定时任务；任务仍在 Codex 中管理。

选岗、申请准备和最终提交按技能规则分步执行。看板本身不会代替你确认或提交申请。
